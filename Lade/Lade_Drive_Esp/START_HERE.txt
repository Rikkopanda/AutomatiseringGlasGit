SYSTEM ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

Two ESP32s communicate via RS-485 Modbus RTU (9600 baud, 8N2):

    Control ESP32              Servo Drive          UI ESP32
    (Master ID=1)            (Slave ID=1)        (Slave ID=2)
    ┌─────────────┐         ┌──────────┐         ┌──────────┐
    │             │         │          │         │          │
    │ Modbus      │         │ Motor    │         │ Modbus   │
    │ Master      │◄───────►│ Control  │         │ Slave    │
    │             │         │ Speed    │         │          │
    │ Driver      │         │ Status   │         │ LCD      │
    │ Control     │         │ Feedback │         │ Encoder  │
    │             │         │          │         │ Buttons  │
    │ Logic &     │         │ Enables  │         │ Keypad   │
    │ Sequencing  │         │ via COM  │         │          │
    │             │         │          │         │          │
    └─────────────┘         └──────────┘         └──────────┘
          │                       │                    │
          └───────────────────────┴────────────────────┘
                    Shared RS-485 Bus
           (A, B lines + GND, 120Ω termination)

MODBUS COMMUNICATION
═══════════════════════════════════════════════════════════════════════════

Registers (UI ESP Slave at ID=2):

    Register 0: SETPOINT         ← Master reads user's speed command
    Register 1: RUN              ← Master reads run/stop flag
    Register 2: CONTROL_MODE     ← Master reads mode bits (reserved)
    Register 3: DRIVE_STATUS     → Master writes drive status to UI
    Register 4: ACTUAL_SPEED     → Master writes feedback speed
    Register 5: UI_STATUS        ← Master reads UI state bits

Polling Schedule:
    • UI ESP: every 100ms
    • Servo Drive: every 200ms
    • Master continuously sends speed setpoints when servo enabled


HARDWARE PINS (Adjustable in modbus_common.h)
═══════════════════════════════════════════════════════════════════════════

Both ESPs - Serial2 (Modbus RTU):
    GPIO 16 (RXD2) ──► RS-485 RX
    GPIO 17 (TXD2) ──► RS-485 TX

UI ESP - I2C Display:
    GPIO 21 (SDA) ──► LCD 16x2 at address 0x27
    GPIO 22 (SCL) ──► (5V pull-up resistors)

UI ESP - Rotary Encoders (2):
    Main:      A=GPIO19, B=GPIO18, Button=GPIO5
    Secondary: A=GPIO17, B=GPIO16, Button=GPIO4

UI ESP - Buttons with LEDs (7 pairs):
    Button GPIO:  32, 33, 34, 35, 36, 37, 38 (input)
    LED GPIO:     25, 26, 27, 12, 13, 14, 15 (output)

UI ESP - Keypad (4x4 Matrix):
    Rows: GPIO 13, 18, 19, 23
    Cols: GPIO 25, 26, 32, 33


GETTING STARTED
═══════════════════════════════════════════════════════════════════════════

1️⃣  BUILD
    cd control-esp && platformio run
    cd ../ui-esp && platformio run

2️⃣  UPLOAD
    # Control ESP (adjust port for your system)
    cd control-esp
    platformio run -t upload --upload-port /dev/ttyUSB0

    # UI ESP
    cd ../ui-esp
    platformio run -t upload --upload-port /dev/ttyUSB1

3️⃣  VERIFY
    # Terminal 1 - Control ESP
    cd control-esp
    platformio device monitor --port /dev/ttyUSB0 --baud 115200
    
    # Terminal 2 - UI ESP
    cd ../ui-esp
    platformio device monitor --port /dev/ttyUSB1 --baud 115200

    Expected: Both boot messages + Modbus initialization

4️⃣  TEST
    • Rotate encoder → Speed changes
    • Press button → LED toggles
    • Check LCD → Shows speed and status
    • Press keypad → Characters appear in serial log

5️⃣  INTEGRATE
    Connect servo drive once Modbus communication is confirmed

Control ESP Main Loop:
    modbusTask();                    // Handle Modbus communication
    driverTask();                    // Update driver state machine
    if (uiRun) {                     // Apply user command
        driverEnable();
        driverSetSpeed(uiSetpoint);
    }
    modbusWriteStatusToUI(status);   // Echo back to UI

UI ESP Main Loop:

    buttonTask();                    // Scan buttons & control LEDs

    lcdTask();                       // Update display

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Issue                       Solution
────────────────────────────────────────────────────────────────────────
No serial output            • Check USB cable & correct port
                           • Verify baud rate (115200)
                           • Check device manager for COM port

Modbus errors              • Verify RS-485 wiring (A, B, GND)
                           • Check drive is in RTU mode (Pn064=2)
                           • Ensure common ground between all devices

LCD not showing            • Verify I2C address 0x27
                           • Check SDA/SCL on GPIO 21/22
                           • Adjust contrast potentiometer

Encoder not working        • Verify GPIO pins in rotary_encoder.cpp
                           • Check for pull-up resistors if noisy
                           • Monitor serial for encoder values

Buttons/LEDs not working   • Verify GPIO pins in button_handler.cpp
                           • Test LED with digitalWrite(pin, HIGH)
                           • Check pull-up on button inputs

For more help: See QUICKSTART.md → Troubleshooting section
